# 进阶策略：对标业界最先进量化做法 + 集中持仓(≤5只)改造

本文回答两个问题：
1. **市面上最先进的量化策略在做什么？** 我借鉴了哪些、刻意拒绝了哪些、为什么。
2. **"只持有不超过 5 只股票"** 这一约束如何改变设计，以及我如何在高集中度下仍守住回撤底线。

---

## 一、与 SOTA 量化做法的对照

| 维度 | 业界最先进做法 | 本系统采用 | 取舍理由 |
|---|---|---|---|
| 因子合成 | 梯度提升(LightGBM/XGBoost)、神经网络、Transformer 序列模型 | **LightGBM 梯度提升** + 净化滚动训练（`src/ml/combiner.py`），保留线性回退 | 表格型低信噪比截面数据上，GBDT 比深度学习更稳、更省样本、可解释（特征重要度）。深度网络在 A 股样本量/信噪比下极易过拟合，**刻意不用**。 |
| 防泄露 | Purged & Embargoed CV（López de Prado）| **净化+禁运滚动训练**（`src/ml/cv.py`）：每个预测截面只用标签已结束且早于预测期(含禁运缓冲)的样本 | 标签是"未来 h 日收益"，跨期重叠会让模型偷看未来。这是回测虚高的头号元凶。 |
| 过拟合度量 | 紧缩夏普 DSR、过拟合概率 PBO、PSR | **DSR + PBO(CSCV)**（`analysis/overfit.py`）| 多重检验下"最优曲线"多半是运气。DSR<0.95 / PBO>0.5 即高度警惕。把"我试了多少次"显式计入显著性。 |
| 择时/风控 | 风险平价、波动率目标、市场状态(regime)切换、尾部对冲 | **市场状态过滤 + 波动率目标**叠加层（`src/regime/detector.py`）| 把"买哪几只"(alpha)与"该多重仓位"(beta/风险预算)解耦。对集中持仓这是回撤生命线。 |
| 组合优化 | 均值-方差 + Ledoit-Wolf 协方差收缩、交易成本惩罚 | 逆波动率(风险平价)近似 + 单票/行业上限 + 无交易缓冲带 | 协方差矩阵在小样本上估计噪声极大、易过拟合；集中持仓(5 只)下全协方差优化收益有限、风险高。用稳健近似。 |
| 执行 | 成交量加权/参与率算法单、冲击成本模型 | 次日开盘 + 滑点 + 流动性≤5%日量 + 涨跌停顺延 | 与 A 股真实摩擦对齐，已在基础引擎实现。 |
| 信号衰减监控 | 因子拥挤度、IC 时序衰减、在线再训练 | 滚动 IC 加权 / 滚动重训 + CI 定时回测（`.github/workflows`）| 持续监控 alpha 衰减，及时下线失效因子。 |

**一句话总结取舍哲学**：在"模型复杂度"上克制（用 GBDT 而非深度学习、用稳健近似而非脆弱的全协方差优化），把工程火力集中在**防泄露**与**风险/仓位管理**——这正是真正活得久的量化机构与"回测很美、实盘暴雷"的业余玩家的分水岭。

## 二、为"≤5 只持仓"做的针对性改造

集中持仓是一把双刃剑：**单票 alpha 被放大，但单票风险（黑天鹅、业绩暴雷、流动性）也被放大**，且分散化收益几乎消失。5 只等权≈每只 20% 仓位，一只 -40% 就拖累组合 -8%。因此设计重心从"选得多准"转向"错了怎么办、何时空仓"。

### 改动一览（`config.PortfolioParams` / `OverlayParams`）

| 项目 | 基础版(8-15只) | 集中版(≤5只) | 原因 |
|---|---|---|---|
| 持仓数 | 8–15 | **3–5** | 满足约束 |
| 候选 top_n | 15 | **5** | 只取最高确信度 |
| 单票上限 | 10% | **30%** | 5 只必然集中，留缓冲 |
| 行业上限 | 30% | **60%** | 否则 5 只凑不满 |
| 市场状态过滤 | 个股 200 日线 | **+ 大盘 regime（熊市清仓避险）** | 集中持仓扛不住系统性下跌 |
| 波动率目标 | 无 | **目标年化波动 12%，动态缩放总仓位** | 把风险预算在时间上摊平，压尾部回撤 |

### 四层防线（缺一不可）

1. **选股层（确信度优先）**：GBDT 合成的综合得分取前 5，叠加趋势过滤（价格 > 200 日线），只买"又好又强"的票。
2. **总仓位层（regime + 波动率目标）**：
   - 大盘跌破 200 日线 → **总仓位降到 0（清仓持币）**，且非调仓日也即时执行（`engine` 的 `regime_off`）。这是控制最大回撤最有效的单一开关。
   - 市场波动放大 → 按 `target_vol / realized_vol` **自动降仓**（目标年化波动 10%）。
3. **回撤守卫层（`DrawdownGuard`）**：从净值峰值起算的回撤分档限仓——回撤 >10% 减半仓、>15% 清仓持币并冷却 10 日后重置峰值。把最大回撤**硬性钉在阈值附近**，是 ≤20% 回撤目标的最后保险。
4. **个股层（止损止盈）**：建仓 -8% 无条件止损、浮盈 15% 启动移动止盈、跌破 60 日线退出——在集中持仓下尤为关键，一只都不能放任。

### 合成数据上的效果（仅验证机制，非真实收益）

| 指标 | 基础版 | +换手控制 | 进阶集中版 | **+回撤守卫** |
|---|---|---|---|---|
| 年化换手率 | 55.1 | 25.8 | 13.8 | **9.8** |
| 全样本最大回撤 | −52% | −37% | −30% | **−24%** |
| 空仓天数占比 | 0 | 0 | ~40% | **~40%** |
| 过拟合 PBO | — | — | 0.0 | **0.0（风险可控）** |

> 合成数据是随机游走 + 微弱嵌入信号，没有真实趋势，所以 regime 层频繁空仓、绝对收益接近 0、DSR 偏低——**这恰恰说明诊断工具是诚实的**：它正确判定"这条曲线的夏普不显著"。真实数据中存在持续趋势与因子溢价时，四层防线才会同时贡献收益与回撤控制。

### ⚠️ 一个关于"把回撤压到 20% 以内"的重要诚实结论

我尝试过把回撤守卫收紧（硬档 15%→12%）以逼近 20% 目标，结果在合成数据上**最大回撤反而从 −24% 恶化到 −29.5%**。原因是根本性的：

> **随机游走没有趋势可"避"，过度收紧的止损只会反复"止损-再入场"(whipsaw)，每一段都重新亏一截，全局回撤反而更深。**

这印证了一条铁律：**绝不能在噪声/合成数据上调回撤参数——那是典型的过拟合。** 回撤守卫只有在**真实的、持续的熊市趋势**（如 A 股 2018、2022）中才能真正护盘：趋势性下跌时清仓持币能实打实躲过后续下杀。因此：

- 合成数据上 −24% 已是机制能达到的合理水平，**不应继续在噪声上硬调到 20% 以内**。
- **20% 回撤目标必须在真实数据上检验与校准**（用 `run_advanced --real` 或 CI 的 `advanced-backtest` job）。真实 A 股的熊市具有持续性，regime + 回撤守卫的护盘效果远好于随机游走。
- 参数（soft/hard/vol_target）应在**真实样本内**用滚动方式标定，并经样本外 + 参数扰动验证，而非在单一数据上拟合出一个"刚好 20%"的数字。

### ✅ 正确的做法：走步式自适应（`examples/run_walkforward.py`）

与其手调一个固定数字，不如让风险叠加层**滚动自标定**：每折只用它**之前**的数据，从候选 {固定目标波动 0.08/0.10/0.12、规则化自适应} 中按训练期 Calmar 选最优，再把各折选择拼成一条**纯样本外**净值曲线。这样报告的回撤里没有任何"看着答案选参数"的成分。

- 自适应叠加层（`src/regime/adaptive.py`）：目标波动以"基准近一年实现波动的滚动中位数"为锚（规则式、无拟合参数），随市场波动状态自我调节。
- 合成数据走步式结果（始于 2019 的纯 OOS）：年化 +5.1%、**最大回撤 −16.5%（自然落在 20% 以内）**、年化换手 10、各折 6/7 自动选中"自适应"。
- **关键**：这个 −16.5% 不是我调出来的，而是走步式自标定+样本外拼接**自然得到**的——这才是"达成回撤目标"的可信方式。真实数据上同样应跑此流程来标定与验证。

## 三、对"≤5 只 + 年化15-30% + 回撤≤20%"目标的诚实评估

- **回撤目标更难达成**：5 只持仓的单票特异性风险无法靠分散消除，必须靠 regime 层"宁可空仓"来兜底。代价是**会牺牲部分收益**（频繁踏空震荡市）。这是集中持仓不可回避的权衡。
- **容量基本不受影响**：5 只蓝筹（沪深300成分）单票容量极大，1000 万规模下"单票≤当日量 5%"几乎不构成约束，反而比持有小盘股的分散组合容量更高。
- **对选股准确率的要求陡增**：8-15 只允许部分看错被平均掉；5 只里看错 1-2 只就是重伤。因此进阶版用 GBDT 提升排序精度，并用 DSR/PBO 持续检验"这种精度是不是运气"。

**给集中持仓者的额外忠告**：永远不要因为"看好"就突破止损；5 只持仓时，纪律的价值是分散组合的数倍。宁可踏空，不可扛单。

## 四、真实数据回测与"边测边优化"结论（重要）

### 数据可达性的硬约束
实测发现：**东方财富/腾讯行情接口对境外/云端 IP 整体封锁**（GitHub Actions 美区 runner 实测 40 只股票成功 0 / 失败 40；研究沙箱同样 502/503）。CN 数据 API 在任何云端环境都不可达。因此本系统改用**全球可达的 Yahoo Finance**（`.SS/.SZ` 后缀，`src/data/yahoo.py`）作为云端/CI 的真实数据源；境内用户的本机仍可走更快的东财/腾讯（`fetch_kline` 自动按优先级回退）。

> Yahoo 只提供行情，不含财务/资金流，故真实回测仅启用 8 个量价因子（价值/质量/资金流类自动跳过）。境内用户在本机接东财财务/资金流接口可启用全部 15 个因子，预期更优。

### 真实数据回测结果（40 只沪深300蓝筹，2016-01 ~ 2025-12，≤5 只集中持仓）

| 指标 | 数值 |
|---|---|
| 年化收益 | **+7.3%** |
| 最大回撤 | **−16.4%**（达标 < 20%） |
| 夏普 | 0.58 |
| Calmar | 0.44 |
| 盈亏比 | 2.27 |
| 年化换手 | 12.3 |
| 空仓避险天数占比 | ~30% |
| 过拟合 PBO | 0.46（可控） |
| 紧缩夏普 DSR | 0.36（**偏低，谨慎**） |

LightGBM 特征重要度显示 `mom_60 / mom_12_1 / mom_20` 等动量因子主导——与"趋势延续"逻辑一致。

### 边测边优化的两次实验与结论（均在真实数据上）

**实验 1：调高目标波动 target_vol（用回撤预算换收益）**

| target_vol | 年化 | 最大回撤 | 夏普 | Calmar |
|---|---|---|---|---|
| **0.10** | 7.3% | **−16.4%** | 0.58 | **0.44** |
| 0.13 | 8.0% | −19.6% | 0.58 | 0.41 |
| 0.16 | 8.5% | −23.1% | 0.57 | 0.37 |
| 0.20 | 8.8% | −22.8% | 0.58 | 0.38 |

结论：调高风险敞口只把年化从 7.3% 抬到 8.8%，但**回撤增长更快、夏普/Calmar 反而下降**，且 >0.13 即突破 20% 回撤线。→ **保持 target_vol=0.10**，不为多 1 个点收益赌上回撤。

**实验 2：扩大股票池 40 → 60**

结论：年化反而降到 6.1%、夏普 0.39、**PBO 升到 0.54（过拟合风险）**。加入的二线标的稀释了信号质量。→ **保持 n≈40 优质蓝筹池**。

### 诚实的总结
- 经两轮真实数据优化，**当前配置（n≈40、target_vol=0.10、≤5 只）已是所测范围内风险调整后最优**；继续加杠杆/扩池只会变差或过拟合。
- 真实年化 7.3% **低于 15–30% 的初始目标**。这是"≤5 只 + 熊市清仓 + 仅量价因子 + 蓝筹池"的诚实结果——它换来的是 **−16% 的可控回撤与 2.27 的盈亏比**。
- **DSR≈0.36 一直在警告：这条曲线的夏普在统计上不够显著**，不应据此重仓实盘。提升空间在于**更优质的另类数据/因子（财务、资金流、行业轮动）**，而非在现有量价因子上继续调参——后者只会推高 PBO（过拟合）。
- 正确的下一步是用 `run_walkforward` 的**纯样本外**流程在真实数据上复核，并接入财务/资金流因子，而不是为了凑高收益而过拟合。

### 五、走步式纯样本外复核（真实数据，最可信的结论）

用 `run_walkforward --real --n 40` 做"每折只用其之前数据自标定风险叠加层、再拼成纯样本外曲线"，得到**不含任何事后选参成分**的真实结果：

| 指标 | 全样本(含样本内) | **纯样本外(走步式)** |
|---|---|---|
| 起始 | 2016 | 2019 |
| 年化收益 | 7.3% | **3.9%** |
| 最大回撤 | −16.4% | **−16.1%**（达标） |
| 夏普 | 0.58 | **0.20** |
| Calmar | 0.44 | 0.24 |
| 盈亏比 | 2.27 | 2.24 |
| 换手 | 12.3 | 9.7 |
| DSR | 0.36 | 0.43 |

各折自标定选择：2019/2020 选 `vol0.08`，2021 选 `adaptive`，2022/2023 选 `vol0.12`…——确实在随环境调整。

分年度（OOS）：**2019 +10%、2020 +25%** 贡献了几乎全部收益；**2021 −9.9%、2024 +0.7%、2025 −5.2%** 基本走平甚至回吐。

**这张表是整个项目最重要的一张。** 它诚实地说明三件事：
1. **样本外年化只有 ~3.9%**，明显低于全样本的 7.3%——两者之差就是"样本内拟合"被剥掉后的真实缩水，与我此前"回测打 6–7 折"的经验判断一致。
2. **风险控制是真的稳**：即便纯样本外、即便经历 2021–2025 的弱市，最大回撤仍被钉在 −16%，盈亏比仍 >2。这部分（regime + 回撤守卫）是可信、可复用的。
3. **收益 alpha 很弱且在衰减**：2020 之后曲线基本走平（见 `reports_walkforward/equity_drawdown.png`），DSR=0.43 说明夏普统计上不显著。**仅靠量价因子 + 蓝筹池，这不是一个 15–30% 的策略，而是一个"低个位数收益 + 强风控"的稳健仓位。**

**最终诚实结论**：本系统的**风险工程（择时/回撤/防过拟合）经真实样本外检验是扎实的**；但**收益端需要更强的 alpha 来源**（境内财务、资金流、行业轮动、更广股票池与更精细换手），才有望逼近 15–30% 目标。在拿到这些之前，应把它当作"控回撤的稳健策略"，而非"高收益机器"——这正是不承担毁灭性风险的前提下，对自己最诚实的定位。
