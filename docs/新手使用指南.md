# 新手使用指南（零基础也能跑）

> 这份指南写给**完全不懂编程**的朋友。照着一步步复制粘贴命令即可，不需要看懂代码。
> 全程大约 15–30 分钟。遇到报错先别慌，翻到文末「常见问题」对照解决。

---

## 0. 先搞清楚：这个东西是什么？它不是什么？

- **是什么**：一套"自动选股 + 自动控制风险"的**研究工具**。你给它一段历史行情，它会用一套量化规则模拟"如果过去这样买卖，结果会怎样"，并画出收益曲线、回撤、各项指标。
- **不是什么**：它**不会**自动帮你下单买股票，**不是**稳赚的"印钞机"，**不构成投资建议**。它的价值是帮你理解策略、验证想法。
- **一句话**：先在历史数据上"纸上谈兵"，看清楚规律和风险，再决定要不要、怎么用真钱。**真金白银前请务必先小资金验证。**

---

## 1. 准备工作：装 Python（只需做一次）

这套程序用 Python 语言写成，需要先在电脑上装好 Python。

### Windows
1. 打开浏览器访问 https://www.python.org/downloads/ ，点黄色按钮下载最新版。
2. 双击安装包。**关键**：第一个界面底部勾选 **「Add Python to PATH」**（添加到环境变量），再点 Install。
3. 装完后，按 `Win + R`，输入 `cmd` 回车，打开「命令提示符」黑窗口。

### Mac
1. 按 `Command + 空格`，输入 `Terminal`（终端）回车，打开终端。
2. 输入 `python3 --version` 回车。如果显示版本号（如 `Python 3.11.x`）就已装好；没有的话去 https://www.python.org/downloads/ 下载安装。

> **怎么判断装好了？** 在黑窗口里输入 `python --version`（Mac 用 `python3 --version`）回车，能看到 `Python 3.10` 或更高版本即可。

## 2. 把项目下载到电脑

**方法 A（推荐，不用装 git）**：
1. 打开本项目的 GitHub 页面，点绿色的 **「Code」** 按钮 → **「Download ZIP」**。
2. 把下载的压缩包解压到一个好找的位置，比如桌面，得到文件夹 `Quantitative-Trading-System`。

**方法 B（会用 git 的话）**：
```bash
git clone <仓库地址>
```

---

## 3. 进入项目文件夹

在第 1 步打开的黑窗口里，输入 `cd ` （cd 后面有个空格），然后把项目文件夹**拖进窗口**（会自动填上路径），回车。例如：

- Windows：`cd C:\Users\你的名字\Desktop\Quantitative-Trading-System`
- Mac：`cd /Users/你的名字/Desktop/Quantitative-Trading-System`

> 之后所有命令都在这个窗口里执行，**不要关掉它**。

---

## 4. 安装依赖（只需做一次）

复制下面这一行，粘贴到黑窗口回车（Windows 用 `python`，Mac 用 `python3`）：

```bash
pip install -r requirements.txt
```

它会自动下载程序需要的工具包，需要等几分钟。看到回到可输入状态、没有红色 `ERROR` 就成功了。

> 网速慢？用国内镜像加速：
> ```bash
> pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
> ```

## 5. 第一次运行：用「模拟数据」跑通全流程（不需要联网）

先用程序自带的模拟数据跑一遍，确认一切正常：

```bash
python -m examples.run_backtest
```
（Mac 用 `python3 -m examples.run_backtest`）

**你会看到**：屏幕滚动打印「因子 IC 评估表」「分年度绩效」等，最后提示「图表已生成」。
**结果图在哪？** 打开项目里的 **`reports/`** 文件夹，有 4 张 PNG 图片：

| 文件名 | 看什么 |
|---|---|
| `equity_drawdown.png` | 上图=资金曲线（越往上越赚），下图=回撤（红色越浅越好） |
| `monthly_heatmap.png` | 每个月赚还是亏（绿赚红亏） |
| `rolling_sharpe.png` | 风险调整后收益的稳定性（在 1 以上较好） |
| `factor_icir.png` | 各选股因子的有效性排名 |

✅ 跑到这里，说明你的环境完全没问题。

## 6. 四个可运行的策略，分别怎么用

把命令复制到黑窗口回车即可。Mac 把 `python` 换成 `python3`。

### ① 基础版（持有 8–15 只，最容易理解）
```bash
python -m examples.run_backtest
```
出图在 `reports/`。

### ② 进阶集中版（最多持有 5 只 + 智能风控，**推荐重点看这个**）
```bash
python -m examples.run_advanced
```
出图在 `reports_advanced/`。这版会在熊市自动空仓避险、控制最大回撤，适合"只想拿几只股票"的人。

### ③ 走步式自适应版（最严谨、最诚实的回测）
```bash
python -m examples.run_walkforward
```
出图在 `reports_walkforward/`。它模拟"每段时间只用过去的数据做决策"，结果最接近真实可信。

### ④ 真实数据版（需要联网，自动下载真实 A 股行情）
```bash
python -m examples.run_real_backtest --n 60
```
- `--n 60` 表示用沪深300里的前 60 只股票（数字可改大改小；越大越慢）。
- 出图在 `reports/`。
- 想试进阶版+真实数据：
  ```bash
  python -m examples.run_advanced --real --n 60
  ```

> **真实数据跑不出来？** 多半是你的网络访问数据接口受限（见文末问题 3）。可以改用 GitHub 在线运行（见第 8 节），或先用模拟数据熟悉流程。

## 7. 怎么看懂结果？（记住这 4 个指标就够）

运行后屏幕会打印一段「绩效」，重点看这几个：

| 指标 | 含义 | 大致好坏 |
|---|---|---|
| `annual_return` | 年化收益率 | 越高越好（本项目目标 15%–30%） |
| `max_drawdown` | 最大回撤（从最高点最多跌多少） | **越接近 0 越好**，目标不超过 −20%（即 -0.20） |
| `sharpe` | 夏普比率（每承担一份风险换来多少收益） | >1 不错，>2 很好 |
| `annual_turnover` | 年换手率（交易频繁程度） | 越低交易成本越省 |

> ⚠️ **重要**：自带的「模拟数据」是随机生成的，收益数字**没有现实意义**，只用来验证程序能跑。**真实表现必须用真实数据（第 6 节④或第 8 节）来看。**

## 8. 不想折腾本地？用 GitHub 在线一键运行（能拿到真实数据结果）

如果本地装环境或网络有困难，可以让 GitHub 的服务器替你跑（它的网络不受限，能下载到真实行情）：

1. 把项目上传到你自己的 GitHub 仓库（或在原仓库有权限）。
2. 打开仓库页面顶部的 **「Actions」** 标签。
3. 左侧选 **「Real-Data Backtest」**，点右侧 **「Run workflow」**，可以填股票数量和时间区间，再点绿色按钮。
4. 等几分钟跑完，点进这次运行记录，最下方 **「Artifacts」** 里下载 `advanced-backtest-report`，里面就是真实数据的收益图和绩效日志。

## 9. 想调参数？只改一个文件就够

所有可调的设置都集中在项目根目录的 **`config.py`** 文件里，用记事本/文本编辑器打开即可看到中文注释，例如：

- `n_holdings_max = 5` —— 最多持有几只股票
- `stop_loss = 0.08` —— 单只股票跌 8% 就止损
- `target_vol = 0.10` —— 目标波动率（越小越保守）

改完保存，再重新运行第 6 节的命令即可。**改之前建议先备份一份**，不确定就别改。

> ⚠️ 切勿对着模拟数据反复调参数去"凑"一个漂亮结果——那叫过拟合，实盘会亏。原因详见 [docs/ADVANCED_STRATEGY.md](ADVANCED_STRATEGY.md)。

## 10. 常见问题（报错对照表）

**问题 1：输入 `python` 提示「不是内部或外部命令」/「command not found」**
- 没装好 Python 或没勾选「Add to PATH」。Windows 重装并勾选；Mac 改用 `python3`。

**问题 2：`pip install` 报红色 ERROR、下载很慢或超时**
- 网络问题。加国内镜像重试：
  ```bash
  pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
  ```

**问题 3：真实数据脚本报「未获取到任何行情 / 502 / 503 / 连接失败」**
- 你的网络访问行情接口受限（公司网/部分地区会这样）。解决办法：换个网络，或用第 8 节的 GitHub 在线运行。先用模拟数据（第 5 节）也完全能熟悉全流程。

**问题 4：安装 `akshare` 时报 `jsonpath` 编译失败**
- 不影响使用！本项目真实数据默认走自带的东方财富接口（只需 `requests`），不依赖 akshare。忽略这个报错即可。

**问题 5：提示缺少某个包，比如 `No module named xxx`**
- 单独补装：`pip install xxx`（把 xxx 换成提示里的名字）。

**问题 6：找不到生成的图**
- 图在项目文件夹下的 `reports/`、`reports_advanced/`、`reports_walkforward/` 里，对应你运行的脚本。

## 11. 最后的安全提醒（务必读）

1. **这是研究工具，不是下单软件，也不是投资建议。**
2. 回测漂亮 ≠ 实盘赚钱。实盘通常要在回测基础上**打 6–7 折**预期，且回撤更深。
3. 真用真钱前，请先长期**纸面跟踪 + 小资金试运行**，并确保你能承受最坏情况的亏损。
4. 风控永远比收益重要——先想着「怎么不亏到伤筋动骨」，再想「怎么赚」。

祝你研究顺利、决策理性 📈
