# A股多因子中低频量化交易系统

> 以10年A股实盘视角设计的、可落地的多因子选股 + 趋势确认 + 波动率管理量化系统。
> 目标：年化 15%–30%，最大回撤 ≤ 20%，策略容量 ≥ 1000 万元，**在不承担毁灭性风险的前提下持续盈利**。

本仓库既是**设计文档**，也是**可运行代码**。`python -m examples.run_backtest` 可在合成数据上一键跑通"数据→因子→中性化→IC评估→滚动权重→回测→绩效"全链路。

> 🔰 **完全不懂编程？** 请直接看 **[新手使用指南（零基础也能跑）](docs/新手使用指南.md)** —— 手把手教你装环境、下载、运行、看结果，复制粘贴即可，约 15–30 分钟。
>
> 📱 **想在 iPhone 上看？** 有移动端看板「量化罗盘」：市场状态仓位 + 当前建议持仓(≤5只) + 真实回测净值/绩效，一屏可扫。本地 `python -m examples.build_dashboard` 生成 `webapp/index.html`；或用 GitHub Pages 每日自动更新后，Safari 打开→「添加到主屏幕」当 App 用。详见下文「📱 手机端」。

```
  data/yahoo.py           Yahoo Finance 行情（国际可达，云端/CI 首选）

  backtest/metrics.py     年化/夏普/回撤/胜率/盈亏比/月胜率/换手率/分年度
  risk/management.py      个股止损/移动止盈 + 组合减仓/熔断 + 流动性 + 回撤守卫
  optimization/rolling.py 滚动IC加权（3年训练/1年验证），防过拟合核心
  ml/cv.py                净化(purge)+禁运(embargo)时间序列CV，防标签泄露

```

设计的第一性原理：**把 alpha（选股）与 beta（择时、风格）解耦**。因子负责选出好股票，行业/市值中性化剥离风格暴露，趋势过滤负责回避系统性下跌，风控负责控制尾部损失。每一层都可独立验证、独立归因。

## 1. 市场与交易规则

全部固化在 `config.TradingRules` / `src/backtest/costs.py` / `engine.py`：

| 规则 | 取值 | 实现位置 |
|---|---|---|
| 印花税（卖出单边） | 0.05% | `costs.trade_cost` |
| 经手费（双边） | 0.00487% | 同上 |
| 过户费（双边） | 0.001% | 同上 |
| 佣金（双边，万2.5，最低5元） | 0.025% | 同上 |
| 滑点 | 0.1%（买入价×1.001，卖出价×0.999） | `engine._fill_*` |
| 涨跌停 | 主板±10%，创业板/科创板±20% | `costs.price_limit` |
| T+1 | 当日买入次日方可卖 | 引擎时序天然保证 |

**单边成本估算**：买入 ≈ 0.0285%（佣金+经手+过户）+ 0.1% 滑点；卖出再加 0.05% 印花税。**一次完整买卖往返显性+隐性成本约 0.33%**。这是中低频（持仓5–20日、年换手率目标 < 8 倍）而非高频的根本原因——成本会吃掉高频策略的全部 alpha。

**涨跌停处理**：`can_buy` 判定开盘一字涨停（开盘价=涨停价且全天最低≥涨停）则买单顺延；`can_sell` 判定一字跌停则卖单顺延。**这是A股最容易被忽视的回测陷阱**——理论信号买到涨停板、止损单卡在跌停板，实盘根本成交不了。

**禁止做空、不用杠杆、次日开盘成交**：引擎只在 `_fill_buy/_fill_sell` 做多头撮合，第 t 日收盘生成指令、第 t+1 日开盘执行。

**股票池过滤**（`universe.build_tradable_universe`，每个调仓日动态重算）：剔除 ST/*ST、上市不满 60 日、近 20 日日均成交额 < 3000 万元的标的。动态重算避免幸存者偏差。

## 2. 策略逻辑与投资哲学

**一句话**：在趋势向上、流动性充足、非垃圾股的范围内，用复合因子选出"便宜 + 强势 + 高质量 + 低波动 + 资金认可"的股票，等权/风险平价持有 5–20 日，用纪律化风控砍掉尾部。

**为什么这套逻辑能长期有效**（行为金融学基础）：
- **价值**：投资者对低估值股票的系统性偏见与修复（处置效应、过度外推）。
- **动量**：信息扩散的滞后与羊群效应导致趋势延续。
- **反转**：短期过度反应后的均值回复，A股散户主导更明显。
- **质量**：市场长期低估"无聊但赚钱"的高ROE公司（质量溢价）。
- **低波动异象**：杠杆约束下投资者追逐高波动彩票股，导致低波动股被低估。
- **资金流**：A股资金驱动特征强，主力资金往往领先价格。

这些都是**根植于人性、不易被套利消除**的结构性现象，因此具有跨周期重复性。

## 3. 数据与因子库（15 个因子）

数据：日线行情（前复权算因子）、财务季度数据（按**公告日**对齐，滞后处理防未来函数）、个股资金流向（主力净流入）。

| 类别 | 因子 | 公式（核心） | 方向 | 直觉 |
|---|---|---|---|---|
| 价值 | `ep` | EPS_TTM / Close | + | 市盈率倒数，越高越便宜 |
| 价值 | `bp` | BPS / Close | + | 市净率倒数，FF价值因子 |
| 动量 | `mom_20` | C_t/C_{t-20}-1 | + | 短中期趋势延续 |
| 动量 | `mom_60` | C_t/C_{t-60}-1 | + | 季度趋势，动量主力 |
| 动量 | `mom_12_1` | C_{t-21}/C_{t-252}-1 | + | 经典12-1，剔除近月反转 |
| 反转 | `rev_5` | C_t/C_{t-5}-1 | − | 短期超跌反弹 |
| 反转 | `boll_lower_bounce` | (MA20−C)/(2·SD20) | + | 近/破布林下轨超卖反弹 |
| 波动 | `vol_20` | std(ret,20)·√252 | − | 低波动异象 |
| 波动 | `atr_ratio` | ATR14 / Close | − | 归一化真实波幅，跨股可比 |
| 资金 | `mf_3d_ratio` | SMA(主力净流入占比,3) | + | 主力连续流入领先价格 |
| 资金 | `vol_surge` | Vol_t / SMA(Vol,20) | + | 量在价先，关注度提升 |
| 质量 | `roe` | 净利润TTM/平均净资产 | + | 核心盈利能力 |
| 质量 | `gross_margin` | (营收−成本)/营收 | + | 护城河与定价权 |
| 质量 | `earnings_stability` | −std(净利同比增速,8季) | + | 盈利可预测，避雷 |

**预处理**（`neutralize_factor`，逐日横截面）：MAD去极值 → z-score标准化 → 对 [行业哑变量 + ln(市值)] 做 OLS 取残差 → 再标准化。剥离风格暴露，留下纯 alpha。

**IC 评估**（`analysis/factor_ic.py`）：逐日 RankIC、ICIR、IC>0 占比、t 统计量、5 分组多空回测。合成数据演示结果（节选，验证机器正确性）：`mf_3d_ratio` ICIR=0.66、`roe`/`gross_margin` 约 0.35，方向与 t 值显著，符合因子设计预期。

## 4. 组合构建与交易执行

- **持仓数**：8–15 只（`PortfolioParams`）。
- **买入**：综合得分排名前 15 **且**价格在 200 日均线上方（趋势过滤通过）。
- **配权**：风险平价（逆波动率 `w_i ∝ 1/σ_i`，默认）或等权；施加单票 ≤ 10%、单行业 ≤ 30%，超限迭代截断后归一（`_cap_weights`）。
- **卖出**（满足其一）：综合得分跌出前 20%；触发 8% 止损；跌破 60 日均线。
- **执行**：每日收盘算信号 → 次日开盘限价单成交，滑点 0.1%，按手（100股）撮合，流动性约束单票 ≤ 当日成交量 5%，未成交顺延。

**换手率控制**（降低成本拖累与净值抖动，三管齐下，均不引入未来信息）：
1. **得分时间平滑**（`smooth_score`，EMA span=5）：只让持续性的相对强弱变化改变持仓。
2. **无交易缓冲带**（`rebalance_band=3%`）：目标与当前权重偏离 < 3% 净值时不调，过滤波动率漂移引起的微调。
3. **持仓滞后/迟滞**（`hold_buffer_rank=40%`）：建仓门槛前 15/20%，但已持仓只有跌出前 40% 才因排名卖出，避免临界股反复进出。
4. 调仓频率 5→10 日（仍居 5–20 日持仓中段）。
> 实测（合成数据）：年化换手率 **55.1 → 25.8（−53%）**，全样本最大回撤 **−52% → −37%**，月胜率与收益同步改善。真实数据上因子更具持续性，换手率会进一步下降。

## 5. 回测与优化

- **区间**：样本内 2016-01-01~2021-12-31，样本外 2022-01-01~2025-12-31。
- **滚动优化**（`rolling_factor_weights`）：每 12 个月，用前 36 个月数据按 **IC 加权**（`w_f ∝ max(ICIR_f,0)`）重标因子权重 + **单类上限 30%** 约束分散，后 12 个月作验证，训练/验证严格不重叠。
- **绩效**（`performance_summary` / `annual_breakdown`）：年化、夏普、最大回撤、Calmar、胜率、盈亏比、月胜率、年化换手率，以及分年度表。
- **稳健性**（`analysis/robustness.py`）：关键参数（止损线、持仓数、调仓频率、趋势均线、权重）逐一 ±20% 扰动（OAT），看夏普是否守住地板、年化离散度是否可控。`robustness_verdict` 给出 `robust` 布尔判定。

> 演示用合成数据仅含微弱嵌入信号，绝对收益不代表真实表现；其价值在于**验证全链路与风控逻辑正确、无未来函数**。真实因子溢价需接入真实数据复现。

## 6. 风险管理（`src/risk/management.py`）

| 层面 | 规则 | 参数 |
|---|---|---|
| 个股 | 建仓后 −8% 无条件止损 | `stop_loss=0.08` |
| 个股 | 浮盈>15%启动移动止盈，回撤超盈利30%止盈 | `trailing_*` |
| 个股 | 跌破60日均线退出 | 引擎判定 |
| 组合 | 当日亏损>5% → 次日减仓至半仓 | `daily_loss_cut=0.05` |
| 组合 | 周回撤>8% → 清仓并暂停交易5个交易日 | `weekly_drawdown_halt=0.08` |
| 流动性 | 单票成交≤当日成交量5%，超出顺延 | `max_pct_of_volume=0.05` |

风控以状态机实现，止损/止盈在收盘判定、次日开盘执行（含跌停卖不出的顺延），与 T+1、涨跌停规则一致。

## 7. 过拟合防范

1. **简单因子**：全部为有经济含义的线性因子，无高阶交互、无神经网络黑箱。
2. **少参数 + 集中管理**：所有参数在 `config.py`，数量可数；信号用线性加权而非自由拟合。
3. **样本外检验**：2022–2025 完全独立于训练区间。
4. **滚动交叉验证**：3年训练/1年验证逐期滚动，权重只由训练窗 IC 决定。
5. **类权重上限**：单类 ≤ 30%，强制分散，限制自由度。
6. **稳健性测试**：参数 ±20% 不应使策略失效。
7. **经济逻辑前置**：先有逻辑再有因子，拒绝纯数据挖掘出的"幽灵因子"。

**为何未来仍可能有效**：策略捕捉的是处置效应、过度反应/反应不足、彩票偏好、质量低估等**根植于人性的行为偏差**。只要市场仍由人（及其训练出的模型）参与、制度仍是 T+1 散户主导，这些偏差就会重复出现——这是 alpha 的来源，也是它不会被快速套利殆尽的原因。

## 8. 实盘衰减估计与三条忠告

**衰减估计**（基于经验的经验法则）：
- 交易成本与冲击成本被低估：回测滑点 0.1% 在 1000 万规模、调仓集中时实际可能 0.15–0.3%，**年化拖累 1–3%**。
- 因子拥挤与 alpha 衰减：公开因子被广泛使用，**alpha 每年自然衰减 10–20%**。
- 涨跌停/停牌导致的成交缺口、财报数据修正、幸存者偏差残留：合计再**折损 2–5% 年化**。
- **综合判断：回测年化打 6–7 折是合理预期。** 若回测年化 25%，实盘 15–18% 为现实目标，且回撤往往比回测更深、更久。

**三条最重要的实盘忠告**：
1. **风控优先于收益，活下来才能复利。** 永远先想最坏情况：止损纪律、仓位上限、熔断机制不可谈判。一次 50% 回撤需要 100% 才能回本——避免毁灭性损失比多赚几个点重要一个数量级。
2. **敬畏交易成本与容量，对冲击成本保持偏执。** 真实滑点、停牌、涨跌停、流动性是 alpha 的头号杀手。1000 万规模务必遵守"单票≤当日量5%"，宁可分批、宁可少做，不要在流动性差的票上硬冲。
3. **相信流程而非单次结果，警惕过拟合。** 短期跑输不等于策略失效，连续多月偏离才需归因。坚持样本外验证、参数扰动、纸面跟踪一段时间再上实盘；任何"完美"的历史曲线都该让你更警惕而非更兴奋。

### 进阶策略（对标 SOTA + 集中持仓≤5只）

详见 **[docs/ADVANCED_STRATEGY.md](docs/ADVANCED_STRATEGY.md)**。相比基础版的升级：
- **非线性因子合成**：LightGBM 梯度提升 + 净化/禁运滚动训练防泄露（`src/ml/`），缺库自动回退岭回归。
- **市场状态识别 + 波动率目标**叠加层（`src/regime/`）：动态调总仓位，熊市清仓避险——集中持仓的回撤生命线。
- **回撤守卫**（`risk.DrawdownGuard`）：从峰值回撤分档限仓（>10%减半、>15%清仓），把最大回撤硬性钉在阈值附近。
- **集中组合**：最多 5 只、单票上限 30%（`config.PortfolioParams`）。
- **过拟合诊断**：紧缩夏普 DSR + 过拟合概率 PBO（`analysis/overfit.py`），量化"曲线是否靠运气"。
- 合成数据上：年化换手 **55→9.8**、最大回撤 **−52%→−24%**、PBO=0。
- ⚠️ **回撤目标须在真实数据上校准**：回撤守卫只在真实持续熊市中有效，在随机游走上过度收紧反而恶化回撤（详见文档"重要诚实结论"）。用 CI 的 `advanced-backtest` job 在真实数据上验证。

### 真实数据接入说明

- 行情(前复权)由 `src/data/eastmoney.py` 直连东方财富公开接口抓取，**仅依赖
  `requests`**，带主机轮询 + 指数退避重试 + parquet 缓存。字段/复权口径已对真实
  返回校验，无需 akshare（其 `jsonpath` 依赖在部分环境编译失败）。
- 资金流/财务数据缺失时，相关因子自动跳过（不影响价格/动量/波动/反转类），
  生产环境可接东财资金流接口或 Tushare 补齐。
- **网络受限环境提示**：若运行环境的网络策略限制了数据 API 主机（返回
  502/503/空），抓取会失败并给出明确提示。此时请在**本机**或**放宽网络策略**的
  环境运行——代码与真实接口完全一致，无需改动。

### 在 GitHub Actions 跑真实回测（CI 出网不受限）

本地沙箱网络策略可能限制数据 API，但 **GitHub 托管 runner 出网开放**，可直连东财跑真实数据。

- `.github/workflows/real-backtest.yml`：手动触发（Actions 页 "Run workflow"，可填股票数/区间）或每周日定时跑；产物 `backtest-report` 含 `reports/*.png` 与 `backtest_log.txt`（绩效全文）。
- `.github/workflows/ci.yml`：每次推送跑冒烟测试 + 合成数据端到端回测（无网络依赖），产物含合成绩效图。
